## Задача 2. Добавление в массив

### Текст задачи

Дана сигнатура функции: `int* add(int arr[], int x, int pos);`
Необходимо реализовать функцию таким образом, чтобы она возвращала новый массив, который будет содержать все элементы массива `arr`, однако в позицию `pos` будет вставлено значение `x`.

**Пример:**
arr = [1, 2, 3, 4, 5], x = 9, pos = 3
результат: [1, 2, 3, 9, 4, 5]

### Алгоритм решения

1. Ограничиваем `pos` диапазоном от 0 до `size`.
2. Выделяем новый массив размером `size + 1` через `new`.
3. Копируем элементы до позиции `pos`.
4. Записываем `x` в позицию `pos`.
5. Копируем оставшиеся элементы со сдвигом на 1.
6. Возвращаем указатель на новый массив.

## Задача 3. Реверс массива

### Текст задачи

Дана сигнатура функции: `void reverse(int arr[]);`
Необходимо реализовать функцию таким образом, чтобы она изменяла массив `arr` - после изменений массив должен быть записан задом-наперёд.

**Пример:**
arr = [1, 2, 3, 4, 5] - arr = [5, 4, 3, 2, 1]

### Алгоритм решения

1. Идём циклом до середины массива (`size / 2`).
2. Меняем местами `arr[i]` и `arr[size - 1 - i]` через временную переменную.
3. Функция возвращает `void`, изменения происходят прямо в исходном массиве.

## Задача 4. Объединение массивов

### Текст задачи

Дана сигнатура функции: `int* concat(int arr1[], int arr2[]);`
Необходимо реализовать функцию таким образом, чтобы она возвращала новый массив, в котором сначала идут элементы первого массива, а затем - второго.

**Пример:**
arr1 = [1, 2, 3], arr2 = [7, 8, 9]
результат: [1, 2, 3, 7, 8, 9]

### Алгоритм решения

1. Выделяем новый массив размером `size1 + size2`.
2. Копируем `arr1` в начало.
3. Копируем `arr2` со сдвигом на `size1`.
4. Возвращаем указатель на новый массив.

## Задача 5. Удаление отрицательных

### Текст задачи

Дана сигнатура функции: `int* deleteNegative(int arr[]);`
Необходимо реализовать функцию таким образом, чтобы она возвращала новый массив, в котором записаны все элементы массива `arr` кроме отрицательных.

**Пример:**
arr = [1, 2, -3, 4, -2, 2, -5]
результат: [1, 2, 4, 2]

### Алгоритм решения

1. Выделяем новый массив максимум на `size` элементов.
2. Идём по исходному массиву, копируем только неотрицательные элементы.
3. Считаем количество скопированных элементов в счётчике и возвращаем его через параметр-ссылку `result_size`.
4. Возвращаем указатель на новый массив.
